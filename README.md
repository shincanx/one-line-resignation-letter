A deterministic Python program that writes the one-line resignation letter of a retry loop — at most 140 characters — to `/output/entry.txt`. The letter: the retry loop waited one second, then two, then four, then eight, and has doubled its patience for the last time.

Entry for the make.fun bounty [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

## Run it

```sh
python3 main.py
```

Writes the letter to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).
